# MQAMTECH Website

A responsive static corporate website for MQAMTECH, built with HTML5, CSS3, JavaScript ES6 and Bootstrap 5.

## Deployment

Upload this repository to GitHub and enable **GitHub Pages** from the main branch. No build process or server is required.

## Contact form

The form includes browser-side validation and a static-hosting confirmation. To receive form submissions automatically, connect it to a form provider such as Formspree or Netlify Forms, or replace the handler in `js/contact.js` with your preferred endpoint.

## Before publishing

- Replace the WhatsApp placeholder number (`212691999014`) with the official business number.
- Review the legal policy wording for your actual practices.
- Add any official photography or project screenshots to `images/`.
